## 2. Contexto y justificación

La línea base académica corresponde al caso ficticio **DistriRápido S.A.C.**, que realiza más de 250 entregas diarias, opera 15 camionetas, tiene combustible y mantenimiento equivalentes al 35% de sus costos, genera aproximadamente 3.5 toneladas de CO₂ mensuales y presenta 22% de entregas fuera de la ventana acordada.

> **Nota de alcance:** por indicación del estudiante, el nombre de la propuesta se personaliza como **EcoLogística Huancayo**. Los datos cuantitativos y condiciones operativas de la consigna se conservan como línea base del caso y no se sustituyen por datos inventados de Huancayo.

## 3. Propósito

Desarrollar un sistema para optimizar rutas de reparto de última milla utilizando metaheurísticas sobre VRPTW/Green VRP, gestionar datos logísticos y medir impacto económico y ambiental.

## 4. Solución propuesta por el estudiante

| Componente | Tecnología | Usuario principal | Propósito |
|---|---|---|---|
| Aplicación Web | Flutter Web | Administrador / Cliente RF-09 | Administración y área de preferencias propias con permisos separados. |
| Aplicación móvil | Flutter | Repartidor | Ruta asignada, entregas, estados, alertas e incidentes. |
| API común | FastAPI/Python | Ambas aplicaciones | Reglas de negocio, seguridad, persistencia y optimización. |
| Base de datos | PostgreSQL | Backend | Integridad, trazabilidad y persistencia. |
| Mockups | Figma | Proyecto | Prototipos Web y móvil antes del desarrollo visual. |

## 5. Objetivo general

Construir un MVP funcional que gestione recursos logísticos, calcule rutas sostenibles, las visualice, permita operación del repartidor y genere indicadores/reportes de sostenibilidad.
