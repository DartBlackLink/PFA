# 13. Análisis multidimensional de restricciones

## 1. Metadatos

| Campo | Valor |
|---|---|
| Proyecto | **EcoLogística Huancayo - Optimizador de Rutas Sostenibles para DistriRápido S.A.C.** |
| Integrante | **Jordy Steve Chancasanampa Torres** |
| Fecha | **27/09/2026** |
| Versión | **1.0.0** |

## 2. Objetivo

Analizar las restricciones realistas del proyecto y conectarlas con decisiones de diseño, mitigaciones y requisitos verificables.

## 3. Matriz de impacto, mitigación y cumplimiento

| Dimensión | Restricción | Impacto | Estrategia de mitigación / diseño | Trazabilidad |
|---|---|---|---|---|
| Salud y seguridad pública | RES-10 / RES-11 / RES-12 | Rutas inseguras, accidentes, visibilidad reducida y vías inadecuadas. | Modelar alertas/incidentes, clasificación vial y restricciones; no presentar una ruta inválida como segura. | RF-03, RF-04, RF-07 |
| Costo del ciclo de vida | RES-01 / RES-05 | El sistema debe considerar costos del ciclo de vida y un presupuesto limitado. | Registrar parámetros de costo, calcular TCO en reportes y controlar presupuesto. | RF-05, RF-06 |
| Cero carbono neto | RES-02 | La operación debe disponer de un plan orientado a neutralidad de carbono. | Medir CO₂, comparar alternativas y generar plan de compensación. | RF-05, RF-06, RF-10 |
| Ambiental | RES-03 | Evitar zonas sensibles y reducir impacto acústico. | Incluir restricciones/penalizaciones geográficas configurables en el optimizador. | RF-03, RF-04 |
| Social / laboral | RES-04 | Jornadas y descansos de conductores. | Validar disponibilidad y restricciones antes de asignar rutas. | RF-03, RF-08 |
| Tecnología | RES-06 | La consigna usa como referencia un stack abierto y operación con conexiones de baja velocidad. | **Propuesta del estudiante:** Flutter Web y Flutter móvil separados como clientes, API FastAPI y PostgreSQL; respuestas compactas, paginación y sincronización controlada. | RNF-01, RNF-04, RNF-05 |
| Cultural | RES-07 | Interfaz en español peruano y comprensible. | Lenguaje claro, iconografía universal y modo conductor simplificado. | RNF-03, RNF-05 |
| Normativa / privacidad | RES-08 | Datos personales y autorización por necesidad de acceso. | RBAC, mínimo privilegio, trazabilidad y minimización de datos. | RNF-02 |
| Datos | RES-09 | Precisión variable de datos geográficos/tráfico. | Validar origen y timestamp; permitir carga manual y degradación controlada. | RF-02, RF-03, RF-07 |
| Seguridad vial | RES-10 | Evitar zonas de alto riesgo y permitir reportes. | Incidentes georreferenciados y capacidad de reoptimización. | RF-04, RF-07 |
| Clima | RES-11 | Neblina/humedad pueden afectar conducción. | Representar condición como restricción/alerta operacional configurable. | RF-03, RF-04 |
| Infraestructura | RES-12 | Calles no pavimentadas pueden ser incompatibles con vehículos pesados. | Clasificar vía y compatibilidad vehículo-vía. | RF-03, RF-04 |

## 5. Matriz de decisiones de diseño

| Decisión | Restricciones que atiende |
|---|---|
| Monolito modular | Costo, mantenibilidad, equipo unipersonal. |
| PostgreSQL | Integridad, trazabilidad y escalabilidad objetivo. |
| Flutter Web + Flutter móvil | Propuesta real de las dos aplicaciones cliente, desarrolladas por separado. |
| Backend FastAPI + PostgreSQL | Centralización de reglas, optimización y persistencia. |
| Servicio cartográfico compatible | Visualización y datos geográficos, evitando acoplar el dominio a un proveedor. |
| Adaptador de tráfico | Variabilidad/indisponibilidad de fuentes externas. |
| RBAC | Privacidad, mínimo privilegio y seguridad. |
| Modo conductor | Usabilidad, contexto cultural y accesibilidad. |
| Métricas ambientales integradas | Cero carbono neto y sostenibilidad. |
| Benchmark del optimizador | Rendimiento y capacidad. |

## 6. Control de cumplimiento

Antes de liberar un incremento se verificará:

- restricciones afectadas;
- evidencia de pruebas;
- impacto en costo;
- impacto ambiental;
- seguridad y privacidad;
- accesibilidad;
- trazabilidad con RF/RNF.
