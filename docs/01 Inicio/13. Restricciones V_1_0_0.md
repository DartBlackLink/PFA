## 2. Matriz multidimensional

| Dimensión | Restricción / impacto | Estrategia de diseño o mitigación |
|---|---|---|
| Salud y seguridad pública | Riesgo de rutas inseguras o datos sensibles expuestos. | RBAC, incidentes, validación de rutas y mínimo privilegio. |
| Costo del ciclo de vida | Debe analizarse TCO y presupuesto limitado. | KPIs y reportes de costo; control presupuestario. |
| Cero carbono neto | Medir emisiones y definir plan de reducción/compensación. | CO₂ por ruta/periodo y módulo de compensación. |
| Ambiental | Evitar zonas sensibles e impacto innecesario. | Restricciones/penalizaciones geográficas configurables. |
| Social/laboral | Respetar disponibilidad y descansos del repartidor. | Validación de disponibilidad antes de asignación. |
| Tecnología | La consigna referencia React/Vue; el alumno elige Flutter. | Registrar como adaptación y validar si el docente exige literalidad. |
| Cultural/UX | Interfaz comprensible y universal. | Figma, iconos claros, accesibilidad y lenguaje consistente. |
| Normativa/privacidad | Datos personales con acceso limitado. | RBAC, minimización, auditoría y consentimiento cuando corresponda. |
| Datos | Calidad variable de GPS/tráfico. | Validación, timestamps, fallback/carga alternativa. |
| Disponibilidad | Red o energía pueden fallar. | Contingencia móvil y reintentos controlados. |

> **Resumen de la tabla:** conecta cada restricción con una decisión de diseño. No basta identificar restricciones; deben influir en arquitectura, backlog o pruebas.
