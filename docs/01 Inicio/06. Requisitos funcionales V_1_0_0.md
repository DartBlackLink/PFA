## 2. Criterio de elicitación

Los RF se conservan desde la consigna y se estructuran para que cada requisito tenga actor, canal, entradas, salida, regla, prioridad y criterio de aceptación. La propuesta del estudiante distribuye el sistema en **Flutter Web para administrador** y **Flutter móvil para repartidor**.

## 4. Regla de canales

| Canal | Usuario | Alcance permitido |
|---|---|---|
| Flutter Web | Administrador | Gestión, planificación, optimización, mapa global, KPIs, reportes y configuración. |
| Flutter móvil | Repartidor | Ruta asignada, pendientes, estados, alertas e incidentes. |
| Backend | Sistema | Reglas, seguridad, persistencia, optimización, reportes e integraciones. |

> **Cómo leer esta tabla:** evita duplicar responsabilidades. El repartidor no administra flota/pedidos y el administrador no necesita usar la aplicación móvil para gestionar el sistema.
