## 2. Marco de elicitación holística y ética

La línea base se obtiene de la consigna oficial del proyecto y se organiza considerando simultáneamente:

- **Operación logística:** flota, conductores, pedidos, clientes y despacho.
- **Contexto glocal:** restricciones geográficas, económicas, sociales, ambientales y normativas descritas por la consigna.
- **Diversidad de usuarios:** administrativos, conductores y clientes con diferentes niveles de alfabetización digital.
- **Sostenibilidad:** distancia, combustible, CO₂, compensación y ciclo de vida.
- **Ética y privacidad:** minimización de datos, autorización por rol y tratamiento responsable de información personal.
- **Seguridad vial:** restricciones de circulación, incidentes y condiciones de infraestructura.
- **Calidad verificable:** cada RF se expresa como comportamiento observable y se acompaña de criterios BDD.

## 3. Catálogo de requisitos funcionales


## RF-01: Gestión de Flota

- **Descripción atómica:** El sistema debe **registrar y administrar vehículos con placa, tipo, capacidad de carga, consumo, factor de emisión y año de fabricación** cuando el usuario autorizado ejecute la operación correspondiente o el flujo operativo la requiera.
- **Prioridad:** Alta

### Criterios de aceptación

#### Ruta Gold
**DADO** que un administrador registra un vehículo con todos los datos válidos,  
**CUANDO** se confirma la operación con datos válidos,  
**ENTONCES** el sistema debe completar el proceso, persistir el estado correspondiente y mostrar una confirmación verificable.

#### Ruta Feliz
**DADO** que se registra un vehículo antiguo con un factor de emisión mayor y una restricción operativa,  
**CUANDO** se utiliza el flujo alternativo permitido,  
**ENTONCES** el sistema debe completar el objetivo sin violar las reglas de negocio ni perder trazabilidad.

#### Ruta Infeliz
**DADO** que se intenta registrar una placa duplicada o datos físicos inválidos,  
**CUANDO** el usuario o un servicio intenta continuar,  
**ENTONCES** el sistema debe rechazar o contener la operación, conservar la consistencia de los datos y mostrar un mensaje explícito sin exponer información sensible.

## 5. Trazabilidad con el MVP

La consigna exige que el MVP implemente al menos el 70% de los requisitos funcionales, priorizando RF-01 a RF-07. RF-08 a RF-10 permanecen en el Product Backlog y deben mantener diseño y trazabilidad aunque su implementación pueda programarse después de las funciones núcleo.
