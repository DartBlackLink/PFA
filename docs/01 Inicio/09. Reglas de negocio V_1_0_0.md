## 3. Reglas del motor de optimización

La función objetivo debe permitir evaluar una solución mediante componentes medibles. Conceptualmente:

```text
CostoTotal =
    w1 * DistanciaTotal
  + w2 * TiempoTotal
  + w3 * ConsumoCombustible
  + w4 * EmisionesCO2
  + w5 * PenalizaciónTardanza
```

Los pesos `w1...w5` son parámetros del modelo y deben documentarse en cada experimento. No deben ocultar restricciones duras como capacidad, disponibilidad o reglas obligatorias.

## 4. Reglas de consistencia

- No crear rutas con pedidos inexistentes.
- No asignar el mismo pedido a dos rutas activas salvo que exista una regla explícita de reintento.
- No eliminar entidades que sean necesarias para mantener trazabilidad histórica; usar estados cuando corresponda.
- Toda reoptimización debe conservar la identificación del escenario anterior y el nuevo.
- Las métricas de ahorro deben identificar la línea base de comparación.

## 6. Control de cambios

Una regla modificada deberá actualizar:

1. requisito afectado;
2. historia o enabler asociado;
3. criterios de aceptación;
4. pruebas;
5. modelo de datos si corresponde;
6. versión del documento.
