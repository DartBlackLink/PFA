> **Cómo leer esta tabla:** resume la identificación y las decisiones base del documento. Permite comprobar que todos los artefactos pertenecen al mismo proyecto, versión e integrante.

## 2. Definición de roles

| Rol | Canal | Objetivo | Acceso |
|---|---|---|---|
| Administrador | Flutter Web | Planificar, administrar y analizar la operación. | Amplio según RBAC. |
| Repartidor | Flutter móvil | Ejecutar la ruta asignada y reportar el estado operativo. | Solo recursos necesarios para su ruta/perfil. |
| Sistema | Backend | Ejecutar reglas, optimización y automatizaciones. | Servicio interno. |

> **Cómo leer esta tabla:** “repartidor” es el rol móvil de ejecución; corresponde al conductor operativo descrito en la consigna. No se define una app independiente para clientes en el MVP.

## 3. Matriz de acceso RBAC

| Capacidad | Administrador Web | Repartidor móvil |
|---|---|---|
| Usuarios/roles | CRUD | Sin acceso |
| Flota | CRUD | Consulta de vehículo asignado |
| Repartidores | CRUD | Perfil propio |
| Clientes | CRUD | Datos mínimos de entrega asignada |
| Pedidos | CRUD | Solo pedidos asignados |
| Optimización | Ejecutar/consultar | Sin acceso |
| Reoptimización | Ejecutar/confirmar | Reporta evento disparador |
| Mapa | Vista global | Ruta propia |
| Dashboard | Completo | Resumen operativo |
| Reportes PDF | Generar/descargar | Sin acceso |
| Incidentes | Gestionar | Crear/consultar propios |
| Auditoría | Lectura autorizada | Sin acceso |

> **Cómo leer esta tabla:** define el límite de permisos por canal. Es referencia para RBAC, pruebas de seguridad y criterios de aceptación.

## 4. Historias de uso resumidas

| Actor | Flujo |
|---|---|
| Administrador | Inicia sesión → gestiona datos → genera rutas → revisa mapa/KPIs → reoptimiza → genera reportes. |
| Repartidor | Inicia sesión → consulta ruta → revisa siguiente entrega → cambia estado → reporta incidente si ocurre. |

> **Cómo leer esta tabla:** muestra el recorrido funcional principal de cada actor y sirve como base para mapa de navegación y mockups Figma.
